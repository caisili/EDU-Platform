# EDU Student MVP v0.1

Clickable UI prototype for Student Home, My Profile, and Discover.

Run:
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## EDU shared Data Layer
Use the same Supabase project as Admin. Copy `.env.example` to `.env.local`, add keys, then run `npm install && npm run dev`. Discover reads school events and Join writes participation back to Admin.
