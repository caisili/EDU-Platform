# EDU Student — Interest Hubs

Discover now supports student-controlled interest hubs.

- Coding: recent live news, school coding/STEM opportunities, coding activities.
- Puzzles: recent live puzzle/logic news, school puzzle/math/chess/STEM opportunities, puzzles.
- Basketball: recent live basketball news and school basketball/sports opportunities; no forced worksheet section.
- Interest choices are stored locally for this pilot build and appear in My Profile.
- School opportunities come only from school-posted events.
- Recent stories use the existing /api/news live RSS route; no fabricated news fallback.
